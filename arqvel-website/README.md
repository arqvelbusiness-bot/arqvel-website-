# ARQVEL — Innovation to the Core

Website for **ARQVEL**, a digital creative agency offering website development, content writing, logo design and branding, digital promotions, lead generation, and billing & POS software.

## Features

- Immersive 3D home screen (Three.js chrome-and-glass centrepiece with cursor interaction)
- Click-to-open pages: Services, Our Approach, Why ARQVEL, Founders, Contact
- Six interactive 3D service cards with detail panels
- Live demo café billing counter in the Billing & POS service
- 3D process timeline, capability constellation and concept showcase
- Founders page with floating 3D hologram cards
- Enquiry form that emails every enquiry to the business inbox via Web3Forms
- Responsive layout, keyboard accessible, respects reduced-motion settings

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Enquiry emails

Enquiries are sent through [Web3Forms](https://web3forms.com). The access key is set in `index.html` (`WEB3FORMS_KEY`). It is a public key and safe to keep in frontend code.
